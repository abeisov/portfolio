# Портфолио — Ануар Беисов

Статический сайт-витрина проектов. Один файл `index.html`, без сборки и зависимостей.

## Как добавить проект

Всё содержимое лежит в массиве `PROJECTS` в начале `<script>` в `index.html`
(блок «ДАННЫЕ — РЕДАКТИРУЕШЬ ТОЛЬКО ЗДЕСЬ»). Ниже массива — пустая заготовка
объекта под копирование и отложенные карточки в комментарии.

Ссылки без адреса пишутся как `url: "#TODO"` — рендерятся неактивными
с пометкой «скоро».

## Структура

    index.html          весь сайт
    files/excel/        таблицы .xlsx, .csv и их HTML-версии
    files/powerbi/      браузерные версии отчётов Power BI
    files/r/            код на R, данные, собранные отчёты
    files/docs/         .pdf, .docx
    img/covers/         скриншоты для обложек карточек
    tools/xlsx2html.py  конвертер .xlsx -> HTML-таблица для просмотра на сайте

## Локальная проверка

    python3 -m http.server 8787

и открыть http://localhost:8787/index.html — встроенные демо (iframe)
работают только по http, при открытии файла двойным кликом они не грузятся.
