# Файлы сайта

Всё, что лежит в этой папке, попадает на GitHub и раздаётся сайтом
по относительному пути. Ссылка в index.html выглядит так:

  { kind: "file", txt: "Скачать .xlsx", url: "files/excel/credit-model.xlsx" }

Куда класть:
  files/excel/ — .xlsx, .xlsm — модели и таблицы     -> kind: "file"
  files/r/     — .R, .Rmd, .qmd — код и отчёты       -> kind: "code"
                 собранный .html отчёт               -> kind: "report"
  files/docs/  — .pdf, .pptx — отчёты и презентации  -> kind: "report" / "slides"

Правила именования:
  - только латиница, цифры и дефис: credit-model.xlsx
  - без пробелов и кириллицы — иначе ссылка ломается
  - не класть сюда ничего под NDA: папка публичная

Ограничения GitHub: один файл — до 100 МБ (после 50 МБ предупреждение).
